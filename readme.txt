# 赛题3 数据集与提交规范

## 一、数据发布说明

本赛题为赛题3水域综合异常识别。

## 二、目标识别类别

共 6 类识别标签：
`乱采`、`乱建`、`乱堆`、`乱占`、`有漂浮物`、`正常`

## 三、数据集划分

数据集分为**训练集**、**测试集**：

1. 训练集标签文件：`train.json`

2. 测试集预测输出格式需与训练集标签格式保持一致

## 四、最终提交文件规范

提交文件为 `.tar.gz` 格式压缩包，压缩包名称自定义，内部目录结构如下：

```Plain Text
自定义名称.tar.gz
├─ code/                # 代码目录
│  └─ 全部项目代码文件
├─ design/              # 智能体方案设计书目录
│  └─ 按赛事规范编写的方案设计文档
└─ result/              # 模型预测结果目录
   └─ 模型输出结果文件 result.json
```
